# Repository Instructions

## Project

This is a coding challenge for Outsera.

Requirements and business rules: @docs/REQUIREMENTS.md

## Commands

- 'install': 'npm install'
- 'start': 'npm start' (env: 'CSV_PATH', 'PORT')
- 'start:example': 'npm run start:example' (loads '.env.example', CSV_PATH=tests/fixtures/ties.csv)
- 'test': 'npm test'
